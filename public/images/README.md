# Images

Drop image files here for activity cards.

Reference them in `data/events.js` using paths like `/images/example.jpg`.

Suggested filenames (matching the starter data):

- `comedy.jpg`
- `baseball.jpg`
- `concert.jpg`
- `theater.jpg`
- `flying-squirrels.jpg`
- `zoo.jpg`
- `garden.jpg`
- `river.jpg`
- `museum.jpg`
- `dc-day-trip.jpg`
- `escape-room.jpg`
- `maymont.jpg`

Images display at roughly 4:3 aspect ratio, ~480px wide. Landscape orientation works best.

If an image is missing, the card shows a colored gradient placeholder with the category name — so the site still looks good without any images.
